# 轉換規則與整合

[回到使用說明](../README.md)

## 轉換順序

1. 套用自訂替換。
2. 使用 OpenCC `s2tw`。
3. 再套用自訂替換，修正 OpenCC 後的詞彙。
4. 依設定處理西式彎引號。

每輪替換先套單字規則，再套詞句例外；詞句採長詞優先。例如先處理后字，再保留「太后、皇后」等完整詞例。新增規則宜使用完整詞組或姓名，避免把里、斗、干等歧義字設成全域例外。

「一出」也不能全文替換成「一齣」：出門、出手及「此言一出」保留動詞用法；「一齣戲、兩齣戲、一齣好戲」以明確詞組處理。

## 共用詞庫

主字典為 `src/s2tw_converter/custom_replacements.tsv`，隨套件提供。它集中維護 metaFinder、epub223 與書庫流程共用的修正；不再要求使用者修改 OpenCC 安裝目錄或維護多份分叉詞庫。

例如完整姓名與出版署名採精確例外，一般詞中的相同單字仍正常轉換。詞庫源自早期 metaFinder、epub223 的自訂詞及保守篩選的外部詞表；OpenCC 原字典不重複匯入。新規則須附正例與反例，避免修一個書名卻誤轉整批正文。

## Python 使用

```python
from s2tw_converter import Converter

converter = Converter()
text = converter.convert('实时信息和“后面”')
```

`Converter` 也可接額外詞檔路徑與 `convert_quotes` 設定。若呼叫端需要先判斷是否存在明確簡體，可使用套件提供的 `simplified_pattern()`；偵測取自 OpenCC 字典並保留已知正體歧義與完整姓名例外。`include_japanese=True` 只適用已確認要轉換的中文欄位，不代表能自動判斷日文與中文語境。

偵測與轉換用途不同：沒有命中不代表語言學上的完整正體認證，命中也不能授權重轉全文。日文引用的保護由呼叫端按結構與語境處理。

## 與其他工具分工

| 工具 | 責任 |
| --- | --- |
| metaFinder | 解析書目，必要時用此共用層正體化 |
| epub223 | 選擇 EPUB 內可讀欄位後呼叫此工具，保護連結、ID 與樣式 |
| ezPub | TXT 建 EPUB，預設不自動簡轉正 |
| CalibreAbout | 決定哪些書目與正文需要轉換，驗證後同步書庫 |

## 維護規則

先修改共用 TSV、補最小回歸測試，再更新使用說明與 CHANGELOG，執行 `python -m pytest -q`。個別書內容或不安全的歧義判斷不寫成全域替換。版本新增了哪些詞例放在 CHANGELOG，操作手冊只描述現行規則。
